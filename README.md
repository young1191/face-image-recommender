# 닮은 캐릭터 이미지 추천

노트북 카메라로 촬영한 한 장의 사진을 준비된 캐릭터 이미지들과 비교해, 시각적으로 가까운 후보를 보여주는 웹 앱입니다. 첫 시제품은 애니메이션·만화·게임 캐릭터 그림을 대상으로 합니다.

## 동작 흐름

1. 브라우저에서 카메라를 켜고 미리보기를 보여줍니다.
2. 사용자가 **비교하기**를 누른 순간 브라우저가 한 장을 캡처합니다.
3. 캡처한 이미지 파일을 Python 웹 앱에 전송합니다. 촬영 사진은 디스크에 저장하지 않습니다.
4. Python의 CLIP 이미지 모델이 촬영 사진과 캐릭터 참고 이미지의 시각적 특징을 비교합니다. 각 캐릭터는 참고 이미지 중 유사도 상위 3장의 평균 점수로 순위를 매깁니다.
5. 가장 점수가 높은 캐릭터 최대 3개의 이름과 기준 사진을 브라우저에 보여줍니다.

브라우저의 JavaScript는 카메라와 화면을 담당하고, Python은 이미지 비교를 담당합니다. 전송 전에 카메라 사진의 긴 변을 최대 640픽셀로 줄여 업로드 크기를 낮춥니다. Python은 시작할 때 참고 이미지 특징을 한 번 계산해 메모리에 보관하고, 비교할 때는 CPU 추론을 사용합니다. 두 부분은 HTTP 요청과 응답으로 연결됩니다. 얼굴을 식별하거나 인물의 신원을 확인하는 앱은 아니며, CLIP 점수는 확률이나 객관적인 닮은 정도가 아닙니다. 그림체, 구도, 배경 등의 영향을 받는 실험적인 시각 유사도 순위입니다.

## 준비할 캐릭터 이미지

각 캐릭터마다 하위 폴더를 만들고, 사용할 수 있는 이미지 파일을 넣습니다. 폴더 이름이 결과 화면에 표시되는 이름입니다.

```text
reference_images/
  캐릭터 이름/
    image-01.jpg
    image-02.png
  다른 캐릭터/
    image-01.jpg
```

지원 형식은 `.jpg`, `.jpeg`, `.png`, `.webp`입니다. 이미지가 많다면 캐릭터 이름별 폴더를 유지한 채 `reference_images` 폴더를 ZIP으로 묶어 전달하거나 복사하세요. 먼저 캐릭터 3~10종, 각 2~5장 정도로 시작해 결과를 확인하세요. 본인이 사용할 권리가 있는 참고 이미지만 준비하세요. 앱은 실행할 때 참고 이미지의 특징을 메모리에 올립니다.

참고 이미지를 여러 장 등록하면 한 장의 우연한 고득점만으로 순위가 정해지는 일을 줄이기 위해, 캐릭터별 상위 3장 점수를 평균합니다. 캐릭터마다 사진이 3장보다 적으면 있는 사진을 모두 사용합니다. 사진 수가 많아져도 얼굴 닮은 정도를 직접 학습하는 것은 아니므로, 실제 결과는 테스트 사진으로 확인해야 합니다.

## 내 노트북에서 실행하기

Python 3.11 또는 3.12를 권장합니다. 프로젝트 폴더에서 가상 환경을 만들고 의존성을 설치합니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

참고 이미지 폴더를 채운 뒤 앱을 실행합니다.

```powershell
python -m uvicorn app:app --host 0.0.0.0 --port 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 처음 실행할 때 CLIP 모델 파일을 인터넷에서 한 번 내려받으므로 시간이 걸릴 수 있습니다. 모델 파일은 앱 서버의 모델 캐시에 보관되며, 촬영 이미지는 저장하지 않습니다.

## 3대의 노트북에서 시연하기

시연을 진행하는 노트북 한 대에서 위 명령으로 앱을 계속 실행하고, HTTPS 임시 접속 주소를 제공하는 터널 서비스를 연결해 그 주소를 공유합니다. 다른 노트북은 설치 없이 브라우저에서 주소를 열고 각자 카메라 권한을 허용하면 됩니다. 카메라 접근에는 보통 HTTPS가 필요합니다(로컬의 `localhost`는 예외).

호스트 노트북은 시연 중 켜져 있고 앱과 터널이 실행 중이어야 합니다. 동시에 요청하면 모두 같은 노트북의 CPU/GPU에서 처리되므로 속도는 장비와 모델 다운로드 상태에 따라 달라집니다. 시연 전에 세 기기에서 접속과 동시 촬영을 확인하세요. 이 초기 버전에는 로그인 기능이 없으므로 임시 주소는 신뢰하는 사람에게만 공유하고 시연 후 터널을 종료하세요. GitHub는 코드 저장에 사용할 수 있지만 앱 실행이나 접속 공유에 필수는 아닙니다.

## 개발 및 테스트

```powershell
python -m unittest discover -s tests -v
```

테스트는 이미지 점수 계산과 참고 이미지 탐색을 확인합니다. 실제 추천 기능은 최초 모델 다운로드가 끝난 후 브라우저에서 시험할 수 있습니다.
